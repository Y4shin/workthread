# out-of-scope

Requests and ideas that were consciously ruled out. A note here answers why
the project does not do something, so the same request is not argued again
every few weeks.

Rules:

- One file per rejected request, named for the request.
- State the request, the decision, the reason, and the condition that would
  reopen it.
- Only the `tw_record_out_of_scope` tool writes these notes. This file is the
  folder's index.
